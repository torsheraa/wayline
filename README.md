# wayline

Редактор путевых точек для JSON-файлов: загрузил файл, отсортировал путь, поправил точки, сохранил.
Это C++ версия программы.

## Что умеет

- импорт JSON (последний файл из запомненной папки или ручной выбор), сохранение в `C:\uni`, экспорт
- сортировка пути: nearest neighbour, 2-opt, 3-opt, Or-opt, ILS и другие, замкнутый маршрут, мосты на длинных прыжках (через существующие точки или новыми точками на линии), по слоям высоты (этаж за этажом)
- редактирование: дубликаты, переименование (в том числе группами с одинаковыми координатами), смена цвета, удаление
- порядок и геометрия: разворот, перемещение вверх/вниз, смещение, масштаб, поворот, разбиение длинных отрезков
- объединение файлов, сравнение двух файлов, пакетная сортировка всех JSON в папке
- вид сверху (XZ) с зумом и выбором точек
- 12 тем, русский и английский, undo/redo
- проверка и установка обновлений через GitHub Releases (меню «Справка»)

Горячие клавиши: Ctrl+O импорт, Ctrl+S сохранить, Ctrl+Shift+S экспорт, Alt+Up / Alt+Down переместить точки, Delete удалить.
